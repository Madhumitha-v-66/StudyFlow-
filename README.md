# StudyFlow - Student Task Manager
StudyFlow is a full-stack web application designed to help students organize academic tasks, manage priorities, set deadlines, and track their progress.

The project was developed as a web development project to demonstrate frontend development, backend integration, database management, routing, and API usage.

## Features
- Create and manage study tasks
- Set task priorities (High, Medium, Low)
- Add due dates to tasks
- Mark tasks as completed
- Delete individual tasks
- Clear all completed tasks
- Search for tasks
- Filter tasks by All, Active, or Completed
- Track task completion progress
- View task statistics
- Display motivational and academic quotes
- Responsive user interface
- Store tasks permanently using MongoDB
